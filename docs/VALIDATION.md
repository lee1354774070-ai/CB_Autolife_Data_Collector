## 未覆盖的范围

- 本轮没有连接机器人、读取实时相机、重启服务或发送动作。
- 四种模式是合成输入的软件集成回归，不是实际手柄、Thor推理或机器人闭环验收。
- 未在目标机验证NVENC/VAAPI、VR同时运行时的负载、长时间录制或新环境完整安装。
- 本机NVML报告驱动/库版本不匹配，但CUDA JPEG测试可以运行；没有修改系统驱动。
  不能据此推断所有GPU功能可用，也不能把安装NVIDIA包等同于可用GPU。
- GPU JPEG可能改变边缘像素；合成测试通过不代表所有真实JPEG或模型效果等价。

性能工具分别测量[SHM与CPU颜色转换](../tests/benchmark_shm_reader.py)、
[JPEG解码](GPU_JPEG_zh.md)和[视频编码](GPU_ENCODING_zh.md)。
它们不替代整机CPU、相机时序、VR延迟及任务完成率的现场测量。
