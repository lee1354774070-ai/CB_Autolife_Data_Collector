# 管理网页电脑播报

电脑播报由 VLA训练配置管理网页承载。Collector 不再启动独立网页、不监听新的HTTP端口，也不输出随机播报链接。网页的登录权限、机器人选择和SSH连接由管理工具统一处理。

## 职责与开关

- 在管理网页中选择明确的机器人和正在运行的采集会话，用户点击开启电脑播报。声音在该电脑播放，关闭播报不能停止Collector。
- `VR_SPEECH=0` 仅关闭原有机器人TTS；VR确认文本仍写入日志，电脑播报可以继续使用。
- `VR_DEBUG_INPUT=0` 默认不刷手柄原始输入。排查时可设为1，保存回执与异常始终保留。
- 原 `PC_SPEECH_WEB` 已移除，无需设置。当前机器人若仍运行旧版本，不热更新、不停止其播报服务；新版本下次部署并重启采集后生效。
- 可选Windows终端客户端仍保留在 `tools/collector_pc_speech.ps1`，共用同一个事件流，不是另一个网页。正常使用管理网页不需要下载它。

## 只读事件接口

管理后台通过已有SSH连接执行，`--base-dir` 指包含 `logs/`、`dataset/` 和 `.official_recording_pids` 的会话目录，**不是** `dataset/` 本身：

```bash
python3 -u /home/ubuntu/CB_Autolife_Data_Collector/collector_pc_speech.py \
  --base-dir /home/ubuntu/nas14/my_task
```

需要避免远端shell解释含空格的路径时，可用互斥的 `--base-dir-b64` 传UTF-8路径的Base64。
`--duration 5` 为最多5秒的只读诊断；不带此参数则跟随至状态来源退出或SSH断开。
未指定目录时只允许当前用户恰好有一个活动采集会话，不选择“最近”的数据。

标准输出每行一个JSON对象，标准库即可运行，无ROS、LeRobot、相机或音频依赖。

| `kind` | 含义和字段 |
|---|---|
| `connected` | 已核实录制器PID、目录和日志。含 `base_dir`、`source`、`mode=vr\|recorder`。从当前EOF开始，不补播历史。 |
| `speech` | 含 `id` 和 `text`。`id` 由日志设备、inode、行结束字节偏移组成；连续相同“下一步”仍是不同事件。 |
| `heartbeat` | 约每2秒表明只读连接仍在运行，不应播报。 |
| `ended` | 源进程退出或有界诊断结束，含 `reason`；**不是** 保存完成。 |
| `error` | 源异常或连接校验失败，含 `text`；立即停止播报并提示核对采集终端。 |

已建立的流附带 `version=1`、`session_id` 和 `seq`。`seq` 从1起递增，包含心跳；
`session_id` 绑定来源模式、录制器PID和日志身份。启动前或读取失败的CLI `error` 可能没有这些字段。
新连接从新EOF开始；旧版本只有原始字段，管理后台如需兼容必须独立分配连接代次，不能把两个连接的事件混合。

## 播报语义

- VR/子任务跟随实际 `[VR speech]` 或 `[VR speech disabled]` 日志，包括倒计时、标记、保存、丢弃及异常。
- 键盘/DAgger跟随录制器已发布回执及后台保存完成日志。`save_queued` 只代表完整暂存，不得显示或播报“已保存”。
- DAgger仅覆盖采集事件，不声称覆盖全部接管/复位/推理状态。
- 回执必须在状态原子写入及相应持久化屏障后发布；写入失败不产生成功提示。
- 同一子任务文本可以重复，去重按事件ID而非文字。子任务总数无固定三步限制。
- 日志替换、截断、源进程退出时停止跟随，绝不自动切换其他任务。Q退出时VR可能先结束，最终保存状态仍以采集终端为准。

## 管理网页接入要求

后台必须沿用登录鉴权和会话权限，通过已有SSH密钥访问指定机器人。
切换机器人/会话、断线或事件序号缺口，应停止当前音频并明确提示；重新开启只接收新事件。
浏览器需要用户点击和可用中文声音；音频队列必须有界，过载/延迟过高时应提示停止，不能静默漏播或继续播放陈旧确认。
该事件流只有日志读权限用途，没有机器人控制接口；不应用于反向触发保存、复位或运动。

## 验证

```bash
python3 -B -m unittest discover -s tests -p 'test_collector_pc_speech.py'
```

此测试使用本地合成日志/进程信息，验证重复提示、回执失败、PID/日志绑定、连接结束和无历史回放，不连接机器人。
管理网页的界面、鉴权、队列及浏览器测试由训练管理工具维护。用户已确认340旧方案可在电脑出声，不能据此认定新网页集成或四模式真实手柄验收完成。
